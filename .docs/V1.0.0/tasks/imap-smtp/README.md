## 审查后明确的责任边界

- Task 03：附件锁覆盖引用提交、回收检查与删除，消除先检查后删除的竞态。
- Task 04：提供用例边界和受控执行入口；Task 08/10/14 首次启用 worker 即接入账号退出保护，Task 15 统一调度和剩余类别接入。
- Task 08：明确拆除 PendingLocal/Synced/DeletedRemote 混用；发送状态归发送任务，定位归 RemoteLocation，本地意图归 mutation。Task 10/14 分别补恢复与归档。
- Task 10：认领标识、尝试版本与实际连接退出共同保证串行，lease 到期不能单独触发并行写。
- Task 13：独占逐夹/逐批收信、下载失败隔离及部分成功交付；仅过滤差集输入恢复 Missing，跳过冷却毒丸继续历史及 IDLE；Task 04 不提前重写同步循环。
- Task 15：clear_local_data 与 flush_due_mutations 复用已有账号退出屏障，清库前停止并等待 mutation，禁止清库后继续远端删除。
- 任务内新增模块、表和函数是待实施设计；仅更新任务文档不表示相关功能已完成。Task 16 在 Task 01 完成后可以提前验收。
